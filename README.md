# Priya Goswami — Portfolio

Deployed link: https://priya-goswami-portfolio.onrender.com

## 💻 About

A personal portfolio website for **Priya Goswami**, a B.Tech Computer Science student specializing in Cloud Computing & Machine Learning. Built to showcase skills, projects, internship experience, and certifications in one place.

## ✨ Features

- 🖥️ Animated typing terminal in the hero section
- 🧭 Sticky navigation with scroll-spy (active section highlights automatically)
- 🎬 Scroll-triggered reveal animations for every section
- 📱 Fully responsive — works cleanly on mobile, tablet, and desktop
- ♿ Accessible — visible keyboard focus states and `prefers-reduced-motion` support
- 🔗 Direct links to live GitHub projects and demos

## 🛠️ Technologies Used

- **HTML5** — page structure
- **CSS3** — styling, layout, responsive design, animations
- **JavaScript (Vanilla JS)** — typing effect, scroll reveal, scroll-spy navigation

No frameworks, no build tools — a single static `index.html` file.

## ▶️ How to Run Locally

1. Clone the repository
   ```
   git clone https://github.com/Priyagoswami30/priya-goswami-portfolio.git
   ```
2. Open the project folder
   ```
   cd priya-goswami-portfolio
   ```
3. Open `index.html` directly in any browser, or use VS Code's **Live Server** extension for auto-reload while editing.

## 🚀 Deploy for Free (GitHub Pages)

1. Push this repo to GitHub (already done if you're reading this on GitHub 🙂)
2. Go to **Settings → Pages**
3. Under **Source**, select the `main` branch and `/ (root)` folder
4. Save — your site will be live at:
   ```
   https://priyagoswami30.github.io/priya-goswami-portfolio/
   ```
